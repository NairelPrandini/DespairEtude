# DespairEtude

DespairEtude is a small hobby project built using Windows Forms and .NET Framework 2.0. The goal of this project is to create a simple visual novel framework that can run on older systems while being fun to experiment with and customize.

## What It Does

- **Main Menu**: A basic menu to start a new game, toggle fullscreen, or exit.
- **Game Interface**: Displays backgrounds, character sprites, and dialogue text.
- **Custom UI Components**: Includes custom panels for smoother rendering.
- **Keyboard Controls**: Simple navigation using the keyboard.

## Why .NET 2.0?

This project uses .NET Framework 2.0 and Windows Forms to ensure compatibility with older systems. It’s a fun way to explore retro-style development while keeping things lightweight.

## How to Run It

1. Clone the repository:
    ```bash
    git clone https://github.com/NairelPrandini/DespairEtude.git
    ```
2. Open the solution file (`DespairEtude.sln`) in Visual Studio.
3. Build and run the project.
